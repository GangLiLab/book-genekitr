5 Protein ID conversion

If you have handled proteomics or metabolomics data (e.g. mass spectrometry), you may need to convert protein IDs to gene IDs before downstream analysis.

5.1 Example data

5.2 ID conversion

Here we will convert protein IDs to gene symbols and compare them with the original data.

protein_id <- rat_prodata[, "Acc"]
gname <- transId(protein_id, "symbol", "rat", unique = T)

new_res <- merge(rat_prodata, gname,
  by.x = "Acc", by.y = "input_id", all.x = T
) %>%
  dplyr::relocate(symbol, .after = Gene)

The Venn plot shows that a number of protein IDs have had their corresponding gene names changed. If users continue to use the old gene names, they may miss out on the latest gene information, or even obtain inaccurate enrichment results.

plotVenn(list(old_name = old_name, new_name = na.omit(new_name)))
